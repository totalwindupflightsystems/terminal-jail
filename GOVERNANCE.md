# Governance

Terminal-jail is maintained by Total Windup Flight Systems.

## Roles

- **Maintainer:** Total Windup Flight Systems — responsible for project direction, releases, and security
- **Contributors:** Anyone who submits accepted pull requests

## Decision Making

- Maintainer makes final decisions on feature scope, API design, and releases
- Contributors propose changes via pull requests with rationale
- Architecture decisions are documented as ADRs in [docs/](docs/)

## Release Process

1. Changes accumulate on `main` branch
2. Release is tagged with semantic version (`vX.Y.Z`)
3. CHANGELOG.md is updated with release notes
4. GitHub release is created with artifacts

## Code of Conduct

This project follows the [Contributor Covenant Code of Conduct](CODE_OF_CONDUCT.md).
